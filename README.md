# youtube-script-prompts-
Open-source AI prompt templates and workflow tools for YouTube scriptwriting and video structuring.
## Features
* **Hook Generators:** High-retention intro templates for the first 30 seconds.
* **Story Structuring:** Pacing guides and narrative arcs for long-form videos.
* **Research Workflows:** Prompts for summarizing complex topics into engaging scripts.

## How to Use
1. Choose a script template from the repository based on your video niche.
2. Insert your topic, key facts, and target audience into the prompt placeholders.
3. Run the workflow using Claude to generate a structured, ready-to-record script.
